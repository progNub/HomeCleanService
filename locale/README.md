# Руководство по локализации (переводу) проекта

В этом проекте используется стандартная система интернационализации (I18N) Django.
Названия полей в админке и статический текст в шаблонах поддерживают русский (`ru`) и английский (`en`) языки.

## Как добавить или изменить перевод

### 1. Подготовка строк в коде
Чтобы текст можно было перевести, он должен быть обернут:
- В Python коде (`models.py`, `views.py`): используйте `gettext_lazy` или `_`.
  ```python
  from django.utils.translation import gettext_lazy as _
  name = _("Текст для перевода")
  ```
- В шаблонах HTML: используйте тег `{% trans %}`.
  ```html
  {% load i18n %}
  <p>{% trans "Текст для перевода" %}</p>
  ```

### 2. Сбор строк для перевода
После внесения изменений в код или шаблоны, выполните команду для обновления файлов `.po`:
```bash
python manage.py makemessages -l en
python manage.py makemessages -l ru
```
Эта команда найдет все новые строки и добавит их в файлы:
- `locale/en/LC_MESSAGES/django.po`
- `locale/ru/LC_MESSAGES/django.po`

### 3. Редактирование переводов
Откройте нужный `.po` файл и найдите строки с пустым `msgstr`. Впишите туда перевод.
Пример:
```po
msgid "Главная"
msgstr "Home"
```

### 4. Компиляция переводов
Чтобы Django "увидел" изменения, их нужно скомпилировать в бинарный формат `.mo`:
```bash
python manage.py compilemessages
```
**Важно:** Всегда запускайте эту команду после редактирования `.po` файлов, иначе изменения не отобразятся на сайте.

## Основные настройки
Конфигурация языков находится в `settings/base.py`:
- `LANGUAGE_CODE = "ru-ru"` (язык по умолчанию)
- `LANGUAGES` (список доступных языков)
- `LOCALE_PATHS` (путь к этой папке `locale/`)
